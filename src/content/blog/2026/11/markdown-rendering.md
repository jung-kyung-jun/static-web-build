본문은 평범한 마크다운입니다. 빌드할 때 HTML로 바뀌고, 사이트의 글꼴과 여백이 입혀집니다.

## 제목과 문단

작은 제목은 본문을 나눕니다. **굵은 글씨**와 *이탤릭*, 그리고 `inline code`도 그대로 쓸 수 있습니다.

### 더 작은 제목

링크는 [Astro 문서](https://docs.astro.build)처럼 적습니다. 사이트 안 글은 태그, 카테고리, 월 목록이 주소를 만들어 줍니다.

## 목록

준비물은 세 가지입니다.

- 마크다운 파일
- 연도와 월이 들어간 폴더
- 제목, 날짜, 카테고리

순서가 있는 목록도 됩니다.

1. 파일을 만든다.
2. frontmatter를 적는다.
3. 빌드한다.

> 초고는 `draft: true`로 두면 목록에 나오지 않습니다. 공개할 준비가 되면 `false`로 바꿉니다.

## 코드

```yaml
title: 글 제목
date: 2026-11-08
description: 한 줄 요약
category: 가이드
tags: [마크다운]
```

```ts
const note = {
  folder: '2026/11',
  slug: 'markdown-rendering',
};
```

## 표

| 항목 | 적는 곳 |
| --- | --- |
| 제목 | `title` |
| 분류 | `category` |
| 꼬리표 | `tags` |

---

이 정도면 글의 뼈대가 갖춰집니다. 이미지는 `public`에 두고 마크다운 이미지 문법으로 넣으면 됩니다.
